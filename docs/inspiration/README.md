# UI Inspiration — captures

Drop your own screenshots of the reference apps here (see `../ui-inspiration.md` for
the curated list and what to study in each).

**Naming:** `<product>-<screen>.png` — e.g.
- `lido-stake-card.png`
- `aave-health-factor.png`
- `yearn-vault-detail.png`
- `jupiter-swap-modal.png`
- `maple-loan-book.png`

**Why captures aren't committed by the assistant:** screenshots of third-party
products are copyrighted; we keep links + notes in `ui-inspiration.md` and use your
own captures here for private design reference only. Avoid using them in any public
marketing for Tide.
